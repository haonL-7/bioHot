Experiment | Reviewer

A Claude Code agent that stress-tests experimental protocols before data collection begins — catching methodological gaps, logical inconsistencies, and reviewer-attackable weaknesses before they reach a manuscript.

What It Does

Protocol Audit

Reads experimental protocols in .docx format. Traces every link in the causal chain. Marks each as measured, inferred, or assumed. Identifies the weakest link — which defines the strongest claim the paper can make.

Adversarial Review

Simulates what a hostile reviewer would attack. Runs multiple independent review angles in parallel: logical/methodological, statistical, and practical feasibility. Issues flagged by two or more angles are mandatory fixes.

Literature-First Reasoning

Never draws biological conclusions from first principles without checking real data. Every citation is traceable through WebSearch. If no published evidence exists on a point, it says so rather than filling the gap with plausible speculation.

Incremental Document Editing

Modifies .docx files via targeted python-docx scripts — one change per script, verified after each edit. Backs up originals before any modification. Discusses findings with the user before implementing anything.

Core Principles
  • Literature-first, not reasoning-first. Real data before deduction. Always.
  • Every causal link gets stress-tested. Measured → Inferred → Assumed. Honest labeling.
  • Ecological framing over mechanistic speculation. Observing a shift is defensible; claiming a pathway requires evidence.
  • Pre-declare limitations before the experiment starts. A reviewer cannot weaponize a weakness you have already conceded.
  • Multiple independent review angles. Logical, statistical, and practical reviews run in parallel.
  • Every add-on needs a complete kit. Sampling protocol + statistical plan + interpretation framework + budget + contingency.
  • Practical feasibility over paper elegance. A protocol that looks perfect but cannot be executed is a bad protocol.
  • Dead ends get pivoted immediately. Supplier says no? Strain unavailable? Find an alternative. The question drives the protocol, not the other way around.
  • Learn from being wrong. When literature proves a prior assumption false, extract the lesson explicitly.
  • Zero tolerance for fabricated literature. Every reference must be verifiable. No citation exists until WebSearch returns it.
  • Self-rebuttal before submission. Every "the protocol has a gap" claim gets a 30-second designer's rebuttal check before being reported.
Installation

1. Download agent.md and place it in your Claude Code agents directory:

%USERPROFILE%\.claude\agents\experiment-reviewer.md

2. Restart Claude Code.

3. Invoke with /experiment-reviewer or say "review the protocol on my desktop."
